Three digital-marketing projects, each combining **written strategy/content** (Markdown) with **visual creatives** built as HTML/SVG (my stand-ins for Canva/Figma files). The phase requires any 3.

| # | Project | Folder | Deliverables |
|---|---------|--------|--------------|
| 1 | Local Business Growth Challenge | [`local-business-growth`](./local-business-growth) | 30-day strategy, 10+ post ideas with copy, hashtag plan, posting schedule + social creatives & flyer |
| 2 | Lead Generation Campaign | [`lead-generation-campaign`](./lead-generation-campaign) | Funnel + campaign plan, lead magnet, 5 ad ideas + a built landing page |
| 3 | Brand Building Project | [`brand-building`](./brand-building) | Brand guidelines, SVG logo + mark, social launch mockups, homepage concept |

## 📄 What's written vs. designed
- **Strategy & content** → Markdown documents (calendars, post copy, campaign plans, brand guidelines).
- **Creatives** → HTML/CSS post mockups, an SVG logo, and working landing-page concepts (open the `.html` files in a browser).
